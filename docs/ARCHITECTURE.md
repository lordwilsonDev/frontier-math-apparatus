# Architecture

## Three coupled graphs

### Research graph
`Question → Hypothesis → Intervention → Observation → Evidence → Result`

### Control graph
`Reference → Controller → Action → Plant → Measurement → Error → Controller update`

### Communication graph
`Sender → Encoding → Message → Channel → Noise → Decoding → Receiver → Interpretation`

A run is considered reconstructable only when these graphs can be related through recorded transitions.

## Cybernetic hierarchy

- L0: mathematical artifact
- L1: experiment
- L2: solver/agent
- L3: research protocol
- L4: verification system
- L5: meta-verification

At each level ask: **Who controls the controller? Can the judged system alter the judge?**
