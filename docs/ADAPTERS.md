# Adapters

## OpenAI/math

The adapter is intentionally outside the core. It should ingest reference metadata, manuscript/result-family identifiers, formalization state, and available result text without leaking reference content into blind execution.

## FCVE

FCVE is a verification adapter. It can provide formal, semantic, computational, adversarial, evidence, and governance checks where applicable. The core apparatus does not assume Lean or any specific verifier.
