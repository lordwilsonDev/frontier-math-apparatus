# Research Protocol

## Phase A — Blind intake

1. Register problem and provenance.
2. Assign terrain/difficulty without revealing the reference answer.
3. Create immutable problem hash.

## Phase B — Question engineering

Produce a canonical question containing referent, proposition, scope, quantifiers, definitions, assumptions, authority, obligations, dependencies, temporal validity, success/failure conditions, and evidence policy.

## Phase C — Representation audit

Record linguistic ambiguities and communication losses, transformations, inventions, and assumptions.

## Phase D — Research generation

Run AIL to invert important assumptions. Generate competing hypotheses/strategies with MoIE. Preserve disagreement.

## Phase E — Blind execution

Execute the selected plan without reference access. Capture derivation, tools, intermediate claims, failures, and candidate result.

## Phase F — Internal verification

Apply available checks. FCVE may be used as an adapter. Do not silently treat external reference agreement as verification.

## Phase G — Reference comparison

Release the quarantined reference. Classify: exact match, equivalent, partial, different form, conditional match, mismatch, unresolved.

## Phase H — Delta analysis

Localize the divergence: interpretation, assumptions, strategy, derivation, calculation, scope, tooling, evidence, or reference disagreement.

## Phase I — Controlled intervention

Change the smallest meaningful control variable practical. Record the intervention explicitly.

## Phase J — Re-solve and transfer

Run the corrected process. Then test the lesson on an unseen problem sharing the hypothesized failure structure.

## Phase K — Deliverable

Produce a complete record containing the problem, canonical question, hypotheses, first attempt, reference comparison, delta, intervention, second attempt, transfer result, final state, and reusable lesson.
