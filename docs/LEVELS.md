# Terrain Levels

Levels are defined by failure regime, not merely problem size.

- L1: advanced/technical reasoning; arithmetic and direct derivation dominate.
- L2: graduate-style multi-step abstraction; conceptual errors become material.
- L3: research-level synthesis; strategy and missing-lemma failures dominate.
- L4: frontier-style problems; decomposition, abstraction, and proof strategy dominate.
- L5: open-frontier/novel terrain; reference may be incomplete and unresolved states are expected.

A level assignment is a hypothesis and must be calibrated empirically from run data.
